# 性能验证（2026-10-24）

## 星空背景

将原有 300 层 CSS radial-gradient 转为 Canvas 的静态绘制，星点参数保存在 `src/data/stars.json`。
保留全部半径、百分比位置、RGB、透明度和叠加顺序；CSS 遮罩与淡出仍随地图缩放变化。
Canvas 只在初次挂载、尺寸或设备像素比变化时重绘，ResizeObserver 回调按动画帧合并。
星云的五层渐变和模糊保持原样。

运行 `pnpm dev` 后访问 `/probe/starfield-performance.html`，点击“运行交替对比”。
对比采用相同星点和遮罩动画，按原渐变、Canvas、Canvas、原渐变顺序运行；每轮忽略前 20 帧，再记录 119 个帧间隔。

本次内置浏览器 1280×720、DPR 1 的结果：

| 方案 | 平均帧间隔 | P95 | 超过 25ms 的帧 |
| --- | --- | --- | --- |
| 原渐变，第 1 轮 | 45.22ms | 63.10ms | 116/119 |
| Canvas，第 1 轮 | 20.85ms | 21.80ms | 0/119 |
| Canvas，第 2 轮 | 20.85ms | 21.70ms | 0/119 |
| 原渐变，第 2 轮 | 45.56ms | 62.60ms | 118/119 |

这是背景遮罩动画的 requestAnimationFrame 测量，不是 GPU 单独耗时，也不代表完整 WebGL 地图或真实手机帧率。
高分屏检查覆盖 390×844 @3x、844×390 @3x、1440×900 @2x 的画布尺寸；未做真实移动设备验收。
实际页面已检查星空、地图和附近面板。构建总 gzip 体积基本不变，此优化主要减少重复绘制开销。

## 面板延迟挂载

面板首次打开前不挂载内容。首次打开也不请求位置；用户点击“用我的位置”才触发浏览器授权与定位。
随后关闭仍保留组件实例、搜索词、标签页和定位结果。附近列表仅在面板打开且显示附近内容时计算。

## 附近电台：浏览器坐标与手动地区（2026-10-24）

本节替代此前的 IP 定位与最近省会推算方案，相关第三方定位调用和城市别名解析逻辑已移除。

- 点击“用我的位置”调用浏览器 Geolocation，使用原始经纬度在本地计算球面直线距离；不反查省市、不调用第三方 IP 定位服务。
- 在已加载的有坐标目录中按距离从近到远展示最多 50 台，播放队列采用同样顺序。新增目录分片到达后重新排序；没有有效坐标的台不参与距离计算。
- 不限制国家或省份，也不设固定半径；标题明确说明是“已加载电台中距离最近的”结果，数据稀疏地区可能出现远处电台。
- 显示浏览器报告的定位精度，距离不展示小数；估算坐标或低精度用户位置按十公里取整。省级和其他估算坐标分别标注“省级位置估算”“位置为估算”。
- 经纬度仅保存在 React 内存中，应用不将其上传或写入持久存储。浏览器自身采用何种系统定位服务由浏览器和操作系统决定。
- 定位需安全上下文（HTTPS 或 localhost）及用户允许。API 超时 10 秒，另设 10.5 秒总期限以防无回调；拒绝、不可用、超时均有提示并允许重试，保留原有结果。
- 保留 34 个省级地区的手动选择，按省会及其他城市展示已有目录。用户手选后，迟到的定位结果不会覆盖选择。
- 只在 sessionStorage 的 `fm:manual-region:v2` 缓存手选地区 30 分钟；旧 IP/设备推算缓存不再读取。禁用存储时仍可手选。

`/probe/drawer-lifecycle.html` 完全模拟浏览器定位，不读取真实设备位置。浏览器回归已覆盖：

- 初始关闭、首次打开均零定位请求。
- 点击后得到原始坐标，列表按距离排序，估算位置标注正确；外部请求数保持 0。
- 拒绝权限后保留已有列表；手动地区选择可用。
- 定位等待期间选择地区，迟到结果不覆盖手选；关闭重开保留选择。
- 切回浏览器定位可再次成功，并恢复距离排序。
