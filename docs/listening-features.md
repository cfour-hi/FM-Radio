# 收听与发现（2026-10-24）

## 睡眠定时

播放器次要信息行提供 15 / 30 / 60 分钟定时，启用后显示剩余分钟，可重新设置或取消。到期停止连接、保留当前台并显示暂停；手动播放会重新连接。

截止时间使用绝对时间，存放于 sessionStorage。同一标签页刷新继续计时；暂停、换台不会重置。到期后刷新不自动续播上次电台。新开会话不继承定时（浏览器复制标签页可能复制会话存储）。存储不可用时，本次页面仍可定时。

在页面恢复可见、重新获得焦点和 pageshow 时重新检查截止时间。系统完全冻结网页执行时，停止动作只能在运行恢复后执行，不能视作系统级闹钟。

## 随机与上一站

右上角骰子展开小面板，范围为全部已加载地图电台、中文（含方言）、当前电台所在地区、收藏。当前地区优先使用电台省份，否则使用国家；不索取用户定位。无当前电台时不可选择地区。

随机排除证书异常和浏览器明确不支持的格式，避开当前台及最近 20 个访问记录；候选耗尽后允许重复，但不会随机回当前台触发暂停。无其他候选时给出提示。范围只约束本次随机选择，目录可播放性不等于实时可用性。

播放器上一站返回实际访问顺序并恢复当时的队列，最多记录 50 次切台，当前页面内有效。返回操作不重复入栈；重试、暂停、继续不入栈。键盘 P 和系统上一曲采用相同的返回逻辑，N / 下一台仍按当前队列切换。

## 语言与类型

电台面板内折叠的“语言与类型”支持常用语言、8 个类型和文本搜索组合过滤。筛选使用全部已加载地图目录和懒加载的无坐标目录，先筛选、合并去重，再排序，每次显示 50 条并支持加载更多。显示匹配总数与当前已显示数量；目录加载失败保留已加载结果并提供重试。切换附近、收藏、最近时清除筛选。

类型使用明确的标签别名，语言合并标准名称、部分代码和常见方言写法。仅展示已整理的语言类别，未标注不凭国别推测。众包标签不代表当前正在播出的节目。

构建脚本保留源语言与标签：地图行在旧 18 列后追加两列，catalog 在旧 5 列后追加两列，解码兼容旧目录。本次按已有 ID 补齐元数据，保留电台数量、地址和地理信息，metadataUpdatedAt 记录元数据更新时间。

## UI 修复与复查（2026-10-24）

- 手机顶栏仅保留短品牌，四个工具入口使用 44px 点击区域；面板位于顶部工具栏下方。随机面板在手机上按视口右侧定位，点击外部、Escape 或打开电台面板均可关闭。
- 播放器将定时移至次要信息行，台名独占主要空间。自动播放被拦截时显示“待播放 / 点击开始收听”，不会用红色错误误导用户。
- 手机播放器可显式收起/展开。56px 迷你模式保留台名、倒计时、播放/暂停；完整控制区同时 inert 和 aria-hidden，避免隐藏控件进入交互。
- 筛选增加“全部”状态及独立可移除条件；折叠后仍看得见已选语言和类型。加载更多每次增加 50 条，修改搜索或筛选时回到首批。
- 提高辅助文字可读性，手机收藏与播放控制采用 44px 点击区域；桌面保持紧凑控制行。
- 浏览器复查覆盖桌面 1280×720、手机视口 390×844 / 320×568。已验证顶部按钮中心实际命中、随机面板边界和外部关闭、迷你播放器播放/暂停与展开、定时取消，以及组合筛选从 50 条加载到 100 条。手机检查为视口模拟，未做真机和软键盘验收。
